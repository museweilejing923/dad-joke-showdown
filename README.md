A program that writes one dad joke to /output/entry.txt.

Entry (100 characters):

> Why did the scarecrow get promoted? He was outstanding in his field — literally, he never leaves it.

## Run it

```sh
python3 main.py
```

## How it works

The program writes a fixed dad joke to `/output/entry.txt`. Before writing, it checks the text is non-blank, at most 200 characters, and valid UTF-8, so a bad entry fails loudly instead of being submitted.
